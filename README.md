# 地图旅行志｜atlas-photo-editorial

**让旅行摄影带着地理信息讲故事。**

这是一个面向旅行实拍照片的图像编辑 Skill：在尽可能保留原始影像内容、构图、色彩和光影的基础上，融入轻薄、无边框的地理地图图层，再以克制的文字、定位标记和微弱的印刷质感，完成一张具有**独立旅行杂志气质**的地理视觉作品。参考小红书siyuhuh的提示词进行修改。

## 设计理念

照片记录到过的地方，地图交代它与世界的关系。

本 Skill 不会把一张旅行照片变成地图海报，而是坚持三个层次：

1. **摄影是主体：** 尽量保留上传照片中的人物、建筑、山体、道路、天空、水面与原始光影。
2. **地图是辅助：** 用透明、无边框的地理线条融入天空、云层、夜色或其他负空间。
3. **排版是点睛：** 用少量地点名称、地理标签与红色位置点建立精致的编辑视觉层级。

## 适用照片

| 照片场景 | 推荐地图元素 |
| --- | --- |
| 雪山、冰川、国家公园 | 等高线、山脊线、已核实的步道和山峰名称 |
| 城市夜景、街头纪实 | 城市路网、街区轮廓、少量地标位置 |
| 湖泊、海岸、河流 | 湖岸或海岸线、周边道路、区域名称 |
| 教堂、寺庙、建筑地标 | 地标周边区域地图、道路与位置点 |
| 自驾、乡野、徒步 | 已确认的道路或步道、地形轮廓 |

## 视觉特色

- **原图优先：** 不主动改造景物，默认维持照片原始长宽比。
- **无框地图：** 地图像半透明线稿印在画面上，不使用方形地图卡片。
- **灵活构图：** 地图通常分布于约 25%—35% 的画面区域；留白不够时自动缩小。
- **克制用色：** 雾蓝、灰白、石墨灰等低饱和线条，与照片原有色调协调。
- **细致排版：** 地名、区域名、可核实的地理标记与小红点；避免堆砌说明。
- **真实地理：** 不编造经纬度、路线、比例尺和精确机位。
- **轻印刷感：** 只加入微弱颗粒和纸张质感，不改变照片本身的氛围。

## 如何使用

### 方法一：在支持 Skill 的工具中使用

将本仓库中包含 `SKILL.md` 的目录，按照你所使用工具的 Skill 安装方式导入；然后上传照片并给出拍摄地点即可。

> 不同工具的 Skill 导入与执行能力不同。仅粘贴 GitHub 仓库链接，不代表所有对话产品都会自动读取、安装或执行该 Skill。

### 方法二：在普通图片编辑对话中使用

即使所用平台不能直接加载 Skill，也可以把 [`SKILL.md`](./SKILL.md) 中的“可直接使用的完整创作指令”作为图片编辑要求。

**最简使用示例：**

```text
请根据 atlas-photo-editorial 的设计规则处理我上传的照片。
拍摄地点：新西兰，库克山国家公园。
请尽量保留原图，仅在合适的负空间融入地图与少量地点标签。
```

**带有位置精度要求的示例：**

```text
请按 atlas-photo-editorial 风格编辑这张城市夜景照片。
拍摄地点：泰国，芭堤雅。
大致区域：步行街附近。
只能标注区域示意位置，不要虚构精确 GPS 或比例尺。
```

**指定地标的示例：**

```text
请将这张教堂照片制作成地理杂志风格。
拍摄地点：新西兰，特卡波湖。
地标：好牧羊人教堂。
地图优先放在天空，保留教堂和雪山的原始细节。
```

## 建议提供的信息

- **照片：** 原始旅行摄影照片，画质越好越有利于保留细节。
- **地点：** 城市、景区或具体地标，建议至少提供一项。
- **拍摄位置（可选）：** GPS 坐标或大致机位；没有就不要填写。
- **偏好（可选）：** 想突出地形、道路、海岸线，或者指定标题语言。

仅提供地点名称时，定位点默认仅表达**大致区域示意**。只有掌握可靠地理信息时，才应绘制真实比例尺、具体路线或精确坐标。

## 参考作品的三种编排方向

以下为适用于不同照片的设计思路，便于理解本 Skill 的自动选择逻辑：

| 场景 | 编排建议 |
| --- | --- |
| 库克山与湖泊 | 在上部天空融入山地等高线、湖泊轮廓和少量山峰标签，保持雪山完整 |
| 芭堤雅夜间街景 | 在较暗的上部区域融入浅色城市路网，尽量避开招牌、人群和车流 |
| 特卡波湖好牧羊人教堂 | 在建筑上方留白区域融入湖泊边界和地标区域地图，避免遮挡教堂 |

如需在 GitHub 首页展示效果图，可以在仓库中新建 `examples/` 目录，上传**你有权公开使用**的示例图片，再根据实际文件名把图片链接加入本节。为避免无效链接，本初始版本不引用尚未上传的图片。

## 使用边界

**照片保真：** 如果使用真正的图层合成，可以最大限度保留底图；如果使用生成式图片编辑，即使指令要求严格保留，细节仍可能变化，不能承诺逐像素一致。

**地图准确性：** 本 Skill 是视觉设计规则，不自带地图数据库，也不能凭照片自动恢复精确 GPS。需要精确路线、比例尺、真实等高线或定位时，应先取得可信地理数据。

**输出格式：** 默认输出一张合成完成的图片。若需要可独立编辑的透明 PNG 地图层或分层工程文件，使用的图像编辑工具必须具备相应输出能力。

## 设计约束

不使用大片遮罩、粗重地图方框、地图应用界面、复杂信息图、无依据的地名坐标、超大旅游标题、霓虹线条或覆盖摄影主体的标签。

最终作品应做到：**远看是一张好照片，近看才发现藏在画面里的地理信息。**
